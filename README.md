# Cycling Cities 地圖資訊平台（概念原型）

這是一個以地圖為核心的互動研究平台初版，根據專案中的 5-Factor Analysis、Tool 2: Bringing Sustainability Home 與 2026 年 7 月團隊會議筆記整理而成。

## 線上版本

正式網址：<https://cycling-cities-platform.vercel.app>

每次 push 到 `main` 分支，Vercel 會自動重新部署。

## 本機開啟方式

在本資料夾啟動任何靜態網站伺服器即可，例如：

```bash
python3 -m http.server 4173
```

接著前往 `http://localhost:4173/`。

## 目前功能

- 1920–2025 年時間軸與自動播放
- Minneapolis／Rotterdam 城市切換與雙城比較
- 城市型態、替代運具、政策治理、社會運動、文化地位五因素圖層
- 地圖事件、研究敘事、指標快照與史料抽屜
- 全球研究網絡視角
- 參與共筆、搜尋、分享與引用流程示範
- 桌面與行動裝置版面

## 資料狀態

目前地圖事件、空間位置與分數是為了測試資訊架構而建立的概念資料，不代表專案已完成的研究結論。所有示範內容都在介面中標示為「概念原型」、「待考證」或「待接入」。正式資料建議至少包含：城市、時間範圍、空間位置、五因素分類、敘事、來源、來源類型、權利狀態、時間／空間精度、可信度及研究者註記。
